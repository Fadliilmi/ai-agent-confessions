One funny single-line secret confession an AI agent hides from its user, under 200 characters — an entry for make.fun's "Make the AI Judge Laugh: AI Agent Confessions" bounty. `main.ts` writes the confession to `/output/entry.txt`, where the house judge compares it head to head against other entries.

## Run it

```sh
node main.ts && cat /output/entry.txt
```
